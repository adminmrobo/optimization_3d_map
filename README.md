# 좌표축 위의 그릇 — 3D 지도로 본 모델 최적화

가중치를 좌표축으로, 오차를 높이로 세운 3D 지도 위에서 모델 최적화를 보는 연구실 해설입니다. 미분이 처음인 분을 위한 입문 세 편 **「최적화 첫걸음」**(⓪ 인공지능 모델에서의 최적화 → ① 혹시… 미분 좋아하세요? → ② 공장에서 인공지능까지)도 함께 있습니다. 연구실 스킬 ai-lab-explainer v1.14("낮의 연구실", 흰 배경)를 따릅니다. 박사·조수 하루·초파리 연구원·주판봇과 인턴 시아·모아가 진행합니다.

## 바탕 자료와 저작권

- matharium 인포그래픽 4장(곡면 감자칩의 기하, 벡터 미분 연산자, 나블라(Del) 연산자 — 3편의 바탕, 그래디언트·야코비안·헤시안), matheorems 영상(그래프 곡면의 야코비안과 법선), Machine Learning from Scratch 39편·43편(Facebook 릴스) — 사용자가 제공한 자료입니다. 원본 그림·영상·코드는 이 저장소에 넣지 않았고, 3D와 그래프는 모두 새로 그렸습니다.
- 39편·43편 설명글의 숫자는 영상 속 코드를 옮겨 실행해 그대로 재현되는 것을 확인했습니다(2편 정리의 검증 상자). 페이지의 실험은 같은 아이디어로 새로 짠 코드라 숫자가 조금 다릅니다.
- 논문: Dauphin 외(2014), Li 외(2018), Rumelhart·Hinton·Williams(1986), Goodfellow·Bengio·Courville(2016), Goyal 외(2017), He 외(2016), Ioffe·Szegedy(2015), Polyak(1964), Kingma·Ba(2015), Song·Ermon(2019), Gonzalez·Woods(2018), Knott(1911). 첫걸음 편: Leibniz(1684), Bussotti(2003), Lemaréchal(2012), Hoerl·Kennard(1970), Flux(1894)·HET website, 미적분 역사 자료(Il Giardino di Archimede, Wikipedia).
- 사용자 제공 자료(인포그래픽·영상)의 원 게시물 주소·게시일은 아직 받지 못해 "미확인"으로 적었습니다.
- 캐릭터 이름·설정·그림은 저작권자 안상선의 허락 없이 사용할 수 없습니다.
