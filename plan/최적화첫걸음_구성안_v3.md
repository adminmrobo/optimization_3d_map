# 최적화 첫걸음 — 미분부터 시작하기 · 구성안 v3.1

- 대상: 미분 개념을 잘 모르는 대학생 (인공지능 모델·공정 최적화 수업의 입문 자료)
- 형식: 연구실 해설 두 페이지 (흰 배경), 연구실 식구 등장, 칸마다 실험·퀴즈, 대결 두 판
- 진행: 하루(조수) → 시아(인턴1) → 모아(인턴2)가 차례로 묻고 박사가 답한다. 초파리 연구원·주판봇이 대결한다.
- 바뀐 점(v2 → v3): 페르소나 검사 1~4순위 반영 — ① 칸마다 "이 칸의 가정" 상자 ② 프롤로그 뒤 "그래프와 기울기 1분 복습" ③ 3.1에서 고정비·가변비 먼저 ④ 4.2에 λ = 한계비용(MC). 5~8순위(공장 숫자 실험, 대결 배치, 역사 압축, 에필로그 식)도 자리를 잡아 둠.
- 추가 정확성 결정: 4.1은 **단기(기계 수 고정)**로 노동만 고른다. 규모수익불변 생산함수에서 노동·자본을 둘 다 고르게 하면 이윤극대 생산량이 하나로 정해지지 않기 때문.

## v3.1 변경 (2026-11-16, 사이트 v1.8)

- 이름: **최적화 첫걸음 — 미분부터 시작하기** ("혹시… 미분 좋아하세요?"는 프롤로그 제목으로 남김)
- 순서: 0장 서론 → 프롤로그(세 질문) → 준비운동(기울기 복습, 번호 없음) → 1장…
- 0장 서론 "모델은 한 번에 만들어지지 않는다" (①편에만)
  - 0.1 신경망 큰 그림 + 뉴런 하나: 입력 0.2·0.5·0.43, 가중치 0.4·0.26·0.3, 편향 0.1 → 0.439 → 시그모이드 0.608. 인포그래픽(ML Tut 「Mathematics Behind AI」)은 순서·숫자만 참고, 그림은 새로 그림
  - 0.2 반복 학습 대시보드: 배터리 셀 불량 뉴런(입력 = 충전 온도, w·b 두 개), 훈련 14·검증 6, 학습률 1.0, 출발 (−1.5, 2.0), 300걸음. 3D 훈련 오차 지도 위 경로 + 훈련·검증 오차 곡선 + 걸음마다 기울기와 고친 양
  - 0.3 여러 측면 성적표: 검증 최저 16걸음(훈련 0.152, 검증 0.441, 재현율 100%) vs 300걸음(훈련 0.030, 검증 0.720, 재현율 67%, 불량 1개 놓침). 순위는 검증으로, 훈련 오차는 외웠는지 점검용, 시험 데이터는 봉인
  - 0.4 피봇팅 = "되돌아가 다시 정비하기": 공장 B(불량이 더 낮은 온도에서 생김), 그대로 쓰기(재현율 33%) / 처음부터 / 이어서 고치기(5·10·20·40걸음). 같은 걸음 수면 이어서 고치기의 검증 오차가 더 낮지만 5걸음 재현율은 처음부터가 높음 — 한 숫자로 판정하지 않음
  - 끝 다리: "매 걸음 방향을 알려 준 것은 기울기 → 그래서 미분"
- 목차 카드: 첫걸음 ①·② 카드에 1~3편과 같은 3D 지도 미리보기(① 언덕 곡면의 접선과 기울기 0인 꼭대기, ② 생산량 곡면 Q = 2√(LK) 위 기계 4대 단면과 L = 16명)
- 난이도 얼굴(울펜스타인 3D 난이도 화면의 발상만 빌림, 게임 그림·문구는 쓰지 않음): 하루 E01 기쁨 → E09 생각 → E20 식은땀 → E24 충격, 단계 이름 산책·오르막·등산·암벽. 배정: 첫걸음 ① 산책, ② 오르막, 그릇 1편 오르막, 2편 등산, 3편 암벽 (편 번호가 클수록 어렵게 — 2026-11-16 수정)

## 미분편 ② — 공장에서 인공지능까지

|---|---|---|---|---|---|
| 4.1 | 모아 | 공장 하나 — 얼마만큼 생산하면 될까요? | 사람 한 명 더 써서 늘어나는 매출(P × MP<sub>L</sub>) = 임금(w)이 될 때까지 고용 | 예시: Q = 2√(L·K), 기계 K = 4대 고정, P = 10, w = 5, r = 10 → L = 16명, Q = 16톤, 이윤 40 | 단기, 완전경쟁, 설명용 예시값(만원·톤·일) |
| 4.2 | 모아 | 목표가 정해졌을 때 — 라그랑지안 | 16톤을 가장 싸게: MP<sub>L</sub>/w = MP<sub>K</sub>/r. **λ = 한계비용(MC)** → 3.2의 MR = MC와 같은 이야기 | 예시: L ≈ 11.3, K ≈ 5.7, 비용 ≈ 113.1, λ = MC ≈ 7.07 | 등식 제약 하나. 부등식(생산능력 한도)은 제조업 편 예고 |

## 숫자 검산 (설명용 예시값, 제작 때 code/check로 다시 확인)

- 4.1: Q = 4√L, MP<sub>L</sub> = 2/√L, 10 × 2/√L = 5 → L = 16, Q = 16, 이윤 = 160 − 80 − 40 = 40
- 4.2: 2√(LK) = 16, K/L = w/r = 1/2 → L = 2K, K = √32 ≈ 5.657, L ≈ 11.314, 비용 = 5L + 10K ≈ 113.14
- 비용함수 C(Q) = (10/√2)·Q ≈ 7.071Q → MC = λ ≈ 7.071 (규모수익불변이라 일정)
- 4.3: P = 7.071이면 수입 = 7.071 × 16 ≈ 113.14 = 비용 → 이윤 0 (오일러 정리)
