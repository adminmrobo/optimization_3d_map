최적화 첫걸음 ⓪ — 인공지능 모델에서의 최적화

인공지능 모델은 어떻게 "배우고", 왜 한 번에 정해지지 않을까?

모델을 학습시킨다는 것은 숫자(가중치) 몇 개에서 수천억 개 이상까지를 오차가 가장 작아지도록 고르는 일, 곧 최적화입니다. 이 편은 미분이나 식 없이 뉴런 하나에서 출발해, 모델이 수백 번 조금씩 고쳐지는 모습, 훈련 점수만 믿으면 안 되는 이유, 데이터가 바뀌면 되돌아가 다시 정비하는 일까지 봅니다. 끝에 남는 질문 하나 — "매번 고칠 방향은 누가 알려 주나?" — 가 다음 편 「혹시… 미분 좋아하세요?」로 이어집니다.

글 · 안상선 ((주)M-Robo 대표) · 저자 소개 · 2026-11-19 · v1.1

세 줄로 먼저
  1. 모델은 한 번에 정해지지 않는다. 오차를 재고 조금 고치는 한 걸음을 수백 번 되풀이해 만들어진다.
  2. 모델은 훈련 데이터로 배우지만, 고르는 기준은 처음 보는 데이터(검증)와 여러 측면의 성적이다.
  3. 데이터가 바뀌면 힘들게 만든 모델도 되돌아가 다시 정비한다. 그리고 매 걸음의 방향은 기울기가 알려 준다.
처음이라면 0.1 → 0.2 → 0.3 → 0.4 순서로 보세요. 식은 "수식으로 보기"를 펼칠 때만 나오고, 칸마다 "이 칸의 가정" 상자가 있습니다. 미분은 ① 편, 경사하강과 역전파는 ② 편에서 다룹니다.

0.3 훈련 점수만 믿으면 안 되는 이유 — 여러 측면 성적표

일상으로 치면
기출문제만 외운 학생은 기출 점수가 만점이지만 처음 보는 문제에서 틀립니다. 그래서 선생님은 외운 문제가 아닌 문제로 따로 시험을 봅니다.
모델에서는
모델은 손에 쥔 데이터로만 만들 수 있습니다. 하지만 목표는 아직 못 본 셀을 잘 맞히는 것입니다. 그래서 손에 쥔 셀을 훈련용과 검증용으로 나누고, 훈련 오차 하나가 아니라 검증 오차, 정확도, 재현율(진짜 불량 가운데 잡아낸 비율)을 함께 봅니다.

어떻게 배우나?오차를 재고, 오차가 줄어드는 쪽으로 조금 고치는 걸음을 수백 번 되풀이한다.0.2
언제 멈추나?훈련 오차가 아니라 검증 오차와 재현율 같은 여러 측면을 보고 고른다. 시험 데이터는 끝까지 봉인.0.3
데이터가 바뀌면?그대로 쓰기·처음부터 다시·이어서 고치기 가운데 고른다. 판정도 한 숫자로 하지 않는다.0.4

용어 대응 카드

가중치·편향 = 모델이 배우는 숫자. 입력에 곱하는 비중과 더하는 기본값.
최적화 = 오차가 가장 작아지는 숫자를 찾는 일.
한 걸음 = 오차를 재고 숫자를 조금 고치는 한 번의 수정.
훈련·검증·시험 = 배우는 몫 · 고르는 몫 · 마지막에 한 번만 여는 몫.
재현율 = 진짜 불량 가운데 잡아낸 비율.
피봇팅(다시 정비) = 데이터가 바뀌었을 때 되돌아가 모델을 다시 고치는 일.

비유의 한계

  • 입력이 온도 하나뿐인 뉴런이라 오차를 3D 지도로 그릴 수 있었습니다. 진짜 모델은 축이 수천~수천억 개 이상이라 지도를 그릴 수 없지만, 걷는 방식은 같습니다.
  • 셀 수가 적어(검증 6개) 셀 하나만 바뀌어도 비율이 크게 흔들립니다. 실무에서는 나누기를 여러 번 바꿔 봅니다.
