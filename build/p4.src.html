미분은 왜 쓰고, 언제부터 있었고, 그걸로 무엇을 할 수 있을까?

인공지능 모델을 학습시키는 일도, 공장의 생산량을 정하는 일도 결국 "가장 좋은 값 찾기", 곧 최적화입니다. 그리고 최적화의 첫 신호는 언제나 기울기에서 나옵니다. 이 편은 미분을 처음 만나는 분을 위해 직선의 기울기에서 출발해, 빵 공장이 하루에 빵을 얼마나 구워야 이익이 가장 큰지까지 함께 걸어갑니다.

업무에서는 — 비수기에 라인을 돌릴까 공장의 성수기·비수기 라인 가동 판단이 같은 계산입니다. 비수기 납품 단가가 "라인을 돌릴 때만 드는 비용"(재료·전기·시간제 인건비)의 단위당 최저보다 높으면 라인을 돌리고, 낮으면 세웁니다. 감가상각·임대료·정규직 기본급처럼 세워도 나가는 돈은 이 판단에서 뺍니다. 단, 비수기가 길게 이어지면 라인 자체를 줄일지(장기 판단)를 따로 봅니다.
수식으로 보기

VC(Q) = 20Q − 3Q² + 0.2Q³, FC = 60. MC = VC′(Q) = 20 − 6Q + 0.6Q², AVC = VC/Q = 20 − 3Q + 0.2Q². AVC 최저점은 Q = 7.5에서 8.75(= 조업중단점), ATC 최저점은 Q ≈ 9.25에서 약 15.85(= 손익분기점). 이윤 최대의 2계 조건: π″(Q) = −MC′(Q) < 0, 곧 MC가 오르는 구간의 교점.

대결 — 손해 나는 날에도 문을 열까?

빵 가격이 하루씩 2만 원, 1만 4천 원, 7천 원으로 바뀝니다. 3.1에서 깨달은 주판봇은 이제 매일 MR = MC로 "가장 많이 남는 판수"를 고릅니다. 다만 "팔아야 돈이 들어온다"며 가게 문은 절대 닫지 않습니다. 초파리 연구원은 같은 방법으로 고르되, 가격이 조업중단점 밑이면 문을 닫습니다. 판정 기준은 세 날 이윤의 합입니다.

MR = MC에서 멈춘다. 가격이 AVC 최저점(8.75) 밑이면 문을 닫는다.

MR = MC로 판수를 고른다. 하지만 문은 절대 닫지 않는다 — 팔아야 돈이 들어오니까.

정리 — 세 질문의 답

질문답 한 줄단계
미분은 왜 쓰나요? (하루)아주 짧은 순간의 기울기로 "지금 얼마나 빨리 변하나"를 잰다. 경제학에서는 '한계', 최적화에서는 "기울기 0 = 꼭대기·바닥의 후보".1.1~1.4
언제부터요? (시아)1660년대 뉴턴, 1684년 라이프니츠의 첫 출판. 19세기에 극한으로 다듬어졌고, 1870년대 한계혁명으로 경제학의 도구가 됐다.2.1~2.3
뭘 할 수 있어요? (모아)빵 공장의 생산량을 MR = MC로 정하고, 조업중단점으로 문을 열지 닫을지 정한다. 공장의 고용과 인공지능 학습은 ② 편에서.3.1~3.3, ②

용어 대응 카드

기울기 = 올라간 양 ÷ 옆으로 간 거리 (Δy ÷ Δx).
미분 = 간격을 0에 가깝게 줄였을 때의 기울기 = 접선의 기울기.
한계 = 하나 더 했을 때 늘어나는 양. 경제학에서 미분의 다른 이름.
편미분 = 나머지는 고정하고 하나만 움직였을 때의 기울기.
전미분 = 모두 함께 조금씩 움직였을 때의 변화 = 편미분 × 움직인 양의 합.
MR = MC = 한 단위 더 팔아 버는 돈 = 한 단위 더 만드는 비용. 이윤 꼭대기의 조건.
조업중단점 = 평균가변비용의 최저점. 가격이 이 밑이면 단기에도 문을 닫는다.
손익분기점 = 평균총비용의 최저점. 가격이 여기면 이윤 0.

비유의 한계

  • 빵 공장은 한 가지 물건, 한 가지 가격만 있는 아주 단순한 모형입니다. 실제 가게는 가격을 스스로 정하기도 하고(이때는 MR ≠ P), 손님 수도 날마다 다릅니다.
  • 한 판 더의 비용과 미분은 비슷하지만 같지 않습니다(1.2). 생산량이 클수록 둘의 차이는 상대적으로 작아집니다.
