좌표축 위의 그릇 — 3D 지도로 본 모델 최적화

가중치를 좌표축으로, 오차를 높이로 세우면 학습은 지도 위의 걷기가 된다.

신경망이 배운다는 것은 가중치라는 숫자를 고쳐 오차를 줄이는 일입니다. 이 해설은 그 일을 3D 지도로 바꿔 봅니다. 1편은 지도를 읽는 수학 — 단면, 기울기와 법선, 굽음(헤시안), 안장점, 야코비안 — 이고, 2편은 그 지도 위에서 사람이 돌리는 다이얼 — 배치, 학습률, 에포크 — 을 실험으로 고르는 이야기입니다. 3편은 1편의 기울기를 낳은 기호 ∇(나블라)를 진짜 x·y·z 세 축 공간으로 가져가 그래디언트·발산·회전·라플라시안을 쉽게 풀어 봅니다.

미분이 처음이라면 → 최적화 첫걸음 — 미분부터 시작하기

"혹시… 미분 좋아하세요?" — 미분을 처음 만나는 분을 위한 두 편입니다. 인공지능 모델이 왜 한 번에 정해지지 않고 여러 번 고쳐지는지(서론)에서 출발해 기울기 복습, 빵 공장의 MR = MC, 공장의 고용과 라그랑지안, 그리고 인공지능의 경사하강·역전파·특성공학까지 이어집니다. 다 보고 나면 아래 그릇 1~3편이 훨씬 쉬워집니다.

1 · 산책미분을 몰라도 OK
2 · 오르막기울기를 알면 OK
3 · 등산그래디언트를 알면 OK
4 · 암벽편미분·벡터가 익숙하면 OK

카드 왼쪽 위의 하루 얼굴이 난이도입니다. 단계가 오를수록 하루의 표정이 굳어 갑니다.

산책●○○○
최적화 첫걸음 ① · 왜, 언제부터, 어디에모델은 한 번에 만들어지지 않는다 · 하루·시아·모아의 세 질문 · 입문
  1. 서론: 반복해서 고치는 모델 — 훈련·검증, 다시 정비하기
  2. 준비운동: 그래프와 기울기 1분 복습
  3. 미분은 왜 쓰나 — 순간의 변화, 한계, 기울기 0, 편미분·전미분
  4. 미분의 역사 — 뉴턴·라이프니츠, 극한, 한계혁명
  5. 경제학의 최적화 — MR = MC, 조업중단점
  6. 대결: 많이 구울수록 이익일까?

  1. 공장 하나 — 사람 한 명 더, 라그랑지안과 λ = 한계비용

  4. 특성공학: 비선형성 vs 상호작용, 규제항

3편 · 화살표 밭 편x·y·z 세 축 공간에서 읽는 ∇(나블라)
  1. 한 방향씩 재 보기 — 편미분
  2. 가장 가파른 오르막 — 그래디언트
  3. 퍼지는가, 모이는가 — 발산
  4. 바람개비가 도는가 — 회전
  5. 이웃보다 움푹한가 — 라플라시안
  6. 대결: 겉모양으로 알 수 있나?
이런 분께경사하강법은 들어 봤지만 그래디언트·헤시안·야코비안이 지도에서 무엇인지 그림으로 보고 싶은 분.
읽는 순서1편 → 2편 → 3편. 2편의 학습률 한계는 1편 ③의 굽음에서 나오고, 3편은 1편 ②의 ∇를 세 축 공간에서 넓힙니다. 3편만 따로 읽어도 됩니다.
